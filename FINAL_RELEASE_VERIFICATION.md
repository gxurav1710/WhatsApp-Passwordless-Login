## 6. Application Creation & Auth Flow Verification

```text
[Developer Application]
       ↓ POST /api/v1/auth/initiate { client_id, phone_number, full_name, email, redirect_uri }
[Auth Core API]
       ↓ Generates "AUTH-XXXX-XXXX", creates AuthAttempt (WAITING_FOR_WHATSAPP), returns deep link
[User WhatsApp Mobile App]
       ↓ Sends "AUTH-XXXX-XXXX" message to bot
[Baileys Worker Daemon]
       ↓ Normalizes JID to E.164, forwards to POST /api/v1/internal/whatsapp/webhook
[Auth Core API]
       ↓ Constant-time match, creates LoginToken (120s TTL), instructs Worker to send reply
[WhatsApp Reply Link]
       ↓ User clicks https://<AuthServerURL>/continue/<TOKEN>
[Auth Core API: GET /continue/:token]
       ↓ Burns token (VERIFIED -> COMPLETED), upserts User, creates AuthCode (60s TTL), sends 302
[Developer Website Callback: /auth/callback?code=<CODE>]
       ↓ POST /api/v1/auth/token { code, client_id, client_secret }
[Authenticated User Session]
       ↓ Returns { access_token, user: { id, fullName, email, phoneNumber } }
```
